# IHL — batch PDF printing for AutoCAD

**[Download the latest version](https://github.com/arcthanhbinhtran-ai/ihl/releases/latest)** · **[Website](https://arcthanhbinhtran-ai.github.io/m5studio/chi-tiet.html?id=ihl&lang=en)** · by [M5 STUDIO](https://arcthanhbinhtran-ai.github.io/m5studio/?lang=en)

Finds the drawing frames in Model space (or every Layout tab) and prints them to PDF in one go. Free for urban planning students, for AutoCAD 2018 – 2027.

- Detects drawing frames by block
- Print by frames in Model space or by Layout tab
- One combined PDF or one file per frame, named after each drawing
- Advanced panel: pick exactly which frames to print, remembers settings per drawing
- Warns about blank printed pages
- Built-in update check

> **Interface language:** Vietnamese for now.

## Install

1. Go to [Releases](https://github.com/arcthanhbinhtran-ai/ihl/releases/latest) and download the installer **`IHL_vX.Y_CaiDat.exe`** (or the zip: unzip it and run `CaiDat.bat`).
2. Close AutoCAD and double-click the installer.
3. If Windows shows “Windows protected your PC”, click **More info → Run anyway** (the installer is not code-signed yet).

This repository only hosts the release files.
